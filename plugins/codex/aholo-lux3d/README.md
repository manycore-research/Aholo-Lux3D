# Aholo Lux3D

This Codex release unit contains the plugin manifest, the production Skill and
its self-contained runtime. It is an internal development build, not a claim of
public availability or complete live-service acceptance.

The immutable ecosystem source code is `1` (Codex); it is set by the adapter,
not by the user or model. The host owns conversation-based confirmation and
external tool invocation. Paid creation requires the integrated deterministic
submission and quote-verification ports.

The offline delivery command preserves original assets and produces one HTML
page for all items and an optional externally assembled scene. It never creates,
queries or retries a cloud task. Unknown service facts remain unknown.
