Install into Codex

First inspect the current configuration:

codex --version
git ls-remote https://github.com/manycore-research/Aholo-Lux3D.git master
codex plugin marketplace list --json
codex plugin list --json

If aholo-lux3d@lux3d version 0.1.0 is already installed, do not reinstall it. If marketplace lux3d points to another source, stop and report the collision. Preserve unrelated plugins, marketplaces, MCP servers, and authentication state.

Install the marketplace and plugin:

codex plugin marketplace add manycore-research/Aholo-Lux3D --ref master --json
codex plugin add aholo-lux3d@lux3d --json

Verify the installation:

codex plugin list --json

Handoff

Report:

  • whether installation was new or already present;
  • plugin id aholo-lux3d@lux3d and version 0.1.0;
  • that a new Codex task is required to load the plugin;
  • that the user can invoke $lux3d or @aholo-lux3d.

Paid generation later requires LUX3D_CN_API_KEY or LUX3D_GLOBAL_API_KEY in the environment. Do not collect an API key during installation and do not claim generation works until a task has actually been submitted.
