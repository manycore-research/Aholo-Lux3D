一条指令，
装进 Codex

复制后贴到任意 Codex 任务。不用下载 zip，也不用去市场里搜。

Paste into Codex aholo-lux3d@lux3d 
/goal Read https://manycore-research.github.io/Aholo-Lux3D/codex-plugin/
已经装了 Codex CLI，直接跑命令 
codex plugin marketplace add manycore-research/Aholo-Lux3D --ref master
codex plugin add aholo-lux3d@lux3d

装完以后

  1. 新开一个 Codex 任务，当前对话不会加载刚装的插件。
  2. 输入 $lux3d 或 @aholo-lux3d 开始生成。
  3. 真正出图时再配置 LUX3D_CN_API_KEY 或 LUX3D_GLOBAL_API_KEY。安装这一步不需要密钥。
仓库需要公开，否则别人的 Codex 拉不下来。 产品站 labs.aholo3d.com
